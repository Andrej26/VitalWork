Data Model

Each participant runs exactly one session; each session runs up to five biofeedback scenarios (A–E); each scenario records a stream of sensor samples.

( Room database, schema v6 · cascade-delete foreign keys · 4 entities )

sensorType
One of 6 types, each mapped to exactly one physical sensor: ESENSE_HEART_RATE, ESENSE_RR_INTERVAL, RESPIRATION (eSense) · WATCH_HR, WATCH_IBI, WATCH_EDA (Galaxy Watch)

NTP-corrected Unix time the sample was taken — on the same timeline across all sensors, so readings line up exactly

Same moment, shown as milliseconds since this scenario started recording
