👤 operator action  📱 app does this automatically
Start — device already in Client mode
Phase 1 — Setup
Ready?📱 battery + notifications must be granted · BLE/mic checked at connect
Create Participant👤 auto anonymous code · starts session (ACTIVE)
Sensor Setup Gate👤 connect Pulse · Respiration · Watch · Proceed unlocks with ≥ 1 sensor
↺ Prerequisites missing → “Start New Session” stays disabled until fixed via the warning card
Scenario Hub — operator picks scenario A–E, or ends the session
Phase 2 — Per-scenario recording loop (repeats for A–E)
Pick Scenario A–E👤 from the scenario hub
Countdown → Recording starts📱 auto-start · NTP timestamp
Capture sensor samples📱 HR · R-R · Respiration · Watch HR/IBI/EDA
Return to Scenario Hub📱 scenario closed · pick next, or end
↺ No sensor connected → “No sensor connected” banner; countdown & recording wait until one connects
End Session👤 from the scenario hub, once all scenarios are done
Phase 3 — Galaxy Watch data transfer (store-and-forward)
Wake the watch📱 remote command · manual tap if it misses
Transfer stored data📱 watch ships buffered HR/IBI/EDA rows
Acknowledge & finalize📱 watch store truncated only after ack
↺ Timeout / abort → session still ends; watch keeps its data for next time
Phase 4 — Finalise & Export
Count collected samples📱 per sensor type · session status → COMPLETED
Upload to server📱 automatic · status → UPLOADED
Retry if it failed👤 manual button on the Review screen
Status → UPLOADED
Export JSON + CSV (optional)👤 manual, to Documents folder — not required for upload
