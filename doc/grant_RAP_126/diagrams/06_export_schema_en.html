Session Export Schema — JSON & CSV

When a session ends, the app automatically uploads it to the VitalWork server. Saving JSON/CSV files locally on the device is a separate, optional step the operator can trigger for a spreadsheet-friendly copy or an offline backup — same data, same shape shown below either way.

Signal gaps aren't stored anywhere directly — they're calculated automatically whenever the data is uploaded or exported.
