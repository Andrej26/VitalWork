Session Export Schema — JSON & CSV

When a session ends, the app automatically uploads it to the VitalWork server. Saving JSON/CSV files locally on the device
is a separate, optional step the operator can trigger for a spreadsheet-friendly copy or an offline backup
— same data, same shape shown below either way.

The upload sends this same data to the VitalWork server in one piece, matched by session code — re-uploading the same session simply replaces it there.
Signal gaps aren't stored anywhere directly — they're calculated automatically whenever the data is uploaded or exported.
